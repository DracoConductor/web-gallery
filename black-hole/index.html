📐 公式

时空几何 — 施瓦西度规

ds² = -(1 - 2M/r) dt²
    + (1 - 2M/r)⁻¹ dr²
    + r²(dθ² + sin²θ dφ²)

r_s = 2GM/c²    事件视界
r_ph = 3GM/c²   光子球
r_isco = 6GM/c²  最内稳定圆轨道

本模拟使用几何单位制 G=c=1

光线追踪 — 零测地线

测地线方程:
d²x^μ/dτ² + Γ^μ_αβ (dx^α/dτ)(dx^β/dτ) = 0

赤道面简化:
d²r/dτ² = (M/r²)(1-2M/r)⁻¹(dr/dτ)²
        + (r-2M)(dφ/dτ)²

光线到达吸积盘时:
D = √(1-2M/r) / (1 - v·n)

D > 1 = 蓝移 / D < 1 = 红移

粒子轨道 — 有效势能

V_eff(r) = (1 - 2M/r)(1 + L²/r²)

轨道方程 (u = 1/r):
d²u/dφ² + u = GM/h² + 3GM/c² u²

轨道类型:
· L > 4M → 双曲飞越或椭圆束缚
· L ≈ √12M → 近圆轨道 (ISCO)
· L < 4M → 螺旋坠入视界
