场景设定

相机在 z=-3 位置，看向 +z 方向
场景：地面平面(y=-1) + 三个球体 + 点光源
红色球 镜面 · 青色球 漫反射 · 金色球 半镜面

1. 光线方程

P = O + t · D
光线从原点 O 沿方向 D 走距离 t，到达 P
← 这是整条渲染管线的基础

2. 球体求交（二次方程）

代入 |O+tD-C|² = R²
a = D·D   b = 2(O-C)·D   c = |O-C|² - R²
Δ = b² - 4ac
if Δ < 0: 未命中   else: t = (-b - √Δ) / 2a (取近点)

3. Lambert 漫反射（明暗）

brightness = max(0, N·L)
N = 表面法线（指向外侧） · L = 指向光源的方向
越正对光源越亮，背面全黑 → 这就是"影子"的由来

4. 镜面反射

R = D - 2(D·N)N
入射方向 D 打中法线 N 的表面，反射方向 R

5. 阴影检测

从命中点向光源再发一条"影子射线"
如果中途被别的物体挡住 → 该点在阴影中
